## Rule

Convex `_generated/api` files do NOT exist until `convex dev` runs. TypeScript compilation will fail if these files are missing.

### MUST DO
- Run `npx convex dev --local --typecheck disable` before any TypeScript compilation
- The `_generated/api.ts` file is auto-generated by the Convex CLI
- Use `npm run dev` which runs `config:generate` then starts Convex + Express + Vite concurrently
- If `CONVEX_DEPLOYMENT` is unset, Convex runs locally on port 3211
- `convex/auth.config.ts` hard-fails if `CONVEX_SITE_URL` is missing

### MUST NOT DO
- Never run `npx tsc --noEmit` before Convex has generated its API files
- Never assume `_generated/` directory contents exist on first clone
- The full Playwright suite cannot enumerate tests due to `tests/imageResolver.spec.ts` broken import
