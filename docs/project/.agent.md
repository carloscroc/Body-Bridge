# Body-Bridge Plane.so Commands Agent

## Description

Provides commands to manage Body-Bridge project tickets and workflows through Plane.so integration. Manual command triggers only - no automatic orchestration.

## Activation

This agent activates when you use these triggers:
- "create a ticket" or "/create-ticket"
- "start symphony" or "/start-symphony"
- "collect evidence" or "/collect-evidence"
- References to BODYBRIDGE ticket identifiers (e.g., BODYBRIDGE-7)

## Scope

**Available commands:**
- `/create-ticket` - Create a new Plane.so ticket
- `/start-symphony` - Start Symphony workflow on an existing ticket
- `/collect-evidence` - Collect evidence without making changes

## When to Use This Agent

Use this agent when you need to:
- Create a new ticket for tracking work
- Start working on an existing ticket (branch + state + evidence)
- Collect evidence without making git changes

## Commands

### /create-ticket

Create a Plane.so ticket for the Body Bridge project.

**Usage:**
```
/create-ticket --name "Ticket Title" --type feature --priority medium
```

**Parameters:**
- `--name` (required): Ticket title
- `--type` (optional, default: feature): One of feature, bug, enhancement, investigation
- `--priority` (optional, default: medium): One of none, low, medium, high, urgent (MUST be string)
- `--description` (optional): Detailed description
- `--files` (optional): Comma-separated file paths to reference
- `--images` (optional): Comma-separated image paths to attach
- `--dry` (optional): Preview without creating

**Critical rules:**
- Priority MUST be a string like "medium", never an integer
- Always dry-run first before creating
- Include file references when relevant (auto-collects git blame)

### /start-symphony

Start the Symphony workflow for a Plane.so ticket — creates branch, moves ticket to "In Progress", collects evidence.

**Usage:**
```
/start-symphony --ticket BODYBRIDGE-7
```

**Parameters:**
- `--ticket` (required): Ticket identifier (e.g., BODYBRIDGE-7)
- `--branch` (optional): Custom branch name (default: symphony/<ticket-slug>)
- `--evidence-only` (optional): Only collect evidence, no git changes
- `--skip-tests` (optional): Skip Playwright tests (use if dev server not running)
- `--skip-screenshots` (optional): Skip screenshot collection

**Safe mode (evidence-only, no git changes):**
```
/start-symphony --ticket BODYBRIDGE-7 --evidence-only --skip-tests --skip-screenshots
```

**Critical rules:**
- Use `--evidence-only` to verify without making git changes
- Use `--skip-tests` if dev server isn't running
- If evidence has failures, ticket stays in current state

### /collect-evidence

Collect evidence for a ticket without changing git state (read-only).

**Usage:**
```
/collect-evidence --ticket BODYBRIDGE-7
```

**Parameters:**
- `--ticket` (required): Ticket identifier (e.g., BODYBRIDGE-7)
- `--skip-tests` (optional): Skip Playwright tests
- `--skip-screenshots` (optional): Skip screenshot collection
- `--skip-security` (optional): Skip security scan

**Evidence types:**
- Automated Tests (Playwright) — requires dev server running at port 7770
- Health Check (GET /api/health on port 3001)
- Code Quality (npx knip dead code scan)
- Security Scan (dependency audit)
- Screenshots (browser capture)
